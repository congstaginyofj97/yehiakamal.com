# yehiakamal.com

Executive personal brand website for **Yehia Kamal El-Din**, Chief Accountant based in Riyadh, Saudi Arabia.

## Overview

This is a static one-page portfolio website designed to present Yehia Kamal El-Din as a credible, experienced, and professional finance/accounting leader.

The website supports professional branding, HR screening, CV sharing, certificate display, and future career opportunities.

## Website Purpose

The website is built to serve two main goals:

1. Build a strong executive personal brand.
2. Support better career and job opportunities.

## Current Features

- Premium dark/gold executive design
- Responsive one-page layout
- Professional profile section
- Expertise and platforms section
- Career timeline
- Certificate gallery with lightbox
- Education and qualifications section
- Downloadable CV and cover letter
- Contact and social links

## Technologies

This project uses:

- HTML
- CSS
- Vanilla JavaScript
- Static assets

No framework, build tool, server, or package manager is required.

## Development Philosophy

This project should remain:

- Simple
- Fast
- Elegant
- Professional
- Easy to maintain

The website owner is not a professional web developer, so every change must remain clear and manageable.
