# AGENTS.md

## Project Rules for AI Assistants

This project is the personal executive portfolio website of Yehia Kamal El-Din, a Chief Accountant based in Riyadh, Saudi Arabia.

The project must remain simple, elegant, fast, and easy to maintain.

## Technology Rules

Use only:
- HTML
- CSS
- Vanilla JavaScript

Do not convert this project to:
- React
- Next.js
- Vue
- Angular
- Any build system

## Design Direction

The website style is:

Executive
Luxury
Professional
Corporate
Dark
Gold-accented

Preserve the current premium dark/gold identity.

Do not make the design colorful, playful, casual, or flashy.

## Code Rules

- Keep code readable.
- Use clear class names.
- Avoid unnecessary complexity.
- Prefer small, safe changes.
- Do not rewrite the whole website unless explicitly requested.
- Explain changes before making large modifications.

## Content Rules

Tone must be:
- Professional
- Executive
- Confident
- Natural
- Suitable for HR managers and finance leaders

Avoid exaggerated marketing language.

## AI Workflow Rules

Before editing files:
1. Understand the task.
2. Read relevant files.
3. Make the smallest safe change.
4. Do not touch unrelated files.
5. Preserve the current visual identity.
6. Wait for approval when asked.

## Important Owner Constraint

The website owner is not a professional web developer.

All changes must remain easy to understand and maintain.
